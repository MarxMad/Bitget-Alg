## El semáforo del taller

Al llegar te preguntaremos tu color:

- 🟢 **Verde:** KYC aprobado, 2FA activo, repo instalado. Llegas directo a la guía 2.
- 🟡 **Amarillo:** KYC aprobado pero falta 2FA o la instalación. Lo resolvemos en la mesa de soporte (14:00–15:00).
- 🔴 **Rojo:** KYC pendiente. Puedes seguir todo el taller con datos públicos y hacer la parte de órdenes en pareja.
