# 0 · Antes del taller

**Hazlo una semana antes.** Crear una API key en Bitget exige tener la cuenta verificada (KYC) y la autenticación en dos pasos (2FA). La verificación puede tardar de minutos a horas, y es lo único que no podemos acelerar en el salón.

## Checklist

- [ ] **1. Crea tu cuenta en Bitget** con el código o enlace de CriptoUNAM (lo compartimos en el registro).
- [ ] **2. Completa el KYC** (verificación de identidad): en la app, **Perfil → Verificación de identidad**. Necesitas tu INE o pasaporte y una selfie. Espera a que diga **"Verificado"**.
- [ ] **3. Activa el 2FA** con Google Authenticator (o similar): **Perfil → Seguridad → Google Authenticator**. Guarda los códigos de respaldo.
- [ ] **4. Revisa el modo de cuenta.** Este repo usa la API v3, que funciona con la **Cuenta Unificada (UTA)**. Si en la configuración de tu cuenta ves la opción de cambiar a Cuenta Unificada, actívala.
- [ ] **5. Abre el modo Demo** una vez para confirmar que tienes saldo simulado: en la app o la web busca el interruptor **Demo / Trading demo**.
- [ ] **6. Instala el entorno** siguiendo la [guía 1](01-instalacion.md).
- [ ] **7. Llena el formulario de check** que te enviamos el día anterior.

## Lo que llevas al taller

- Laptop con cargador (macOS, Windows o Linux).
- Tu celular con la app de Bitget y Google Authenticator.
- Tu contraseña de Bitget (vas a crear la API key ahí mismo).

## Lo que NO necesitas

- Dinero: todo es en modo demo.
- Saber programar a nivel avanzado: si sabes correr un comando en la terminal, puedes seguir el taller.

## ¿Y si mi KYC no se aprueba a tiempo?

Puedes hacer todo el taller excepto conectar tu propia API key: descargar datos y hacer backtests usa la **API pública**, que no requiere llaves. La parte de órdenes la haces en pareja con alguien que ya tenga su key.
